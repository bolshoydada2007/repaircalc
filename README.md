# RepairCalc — умный подбор стройматериалов для ремонта

Веб-сервис, который не просто считает расход материалов, а объясняет,
что и почему подходит: учитывает тип помещения (ванная, кухня, комната),
влагостойкость, бюджет и даже фотографию комнаты.

## Что умеет

- **Обычный калькулятор** — расход и стоимость материалов на площадь.
- **Умный подбор** — выбирает подходящие товары из реального каталога
  (Максидом), сортирует по бюджету и объясняет каждый выбор словами
  («влагостойкая — подходит для ванной», «класс 33 соответствует
  сегменту премиум»).
- **Подбор по фото помещения** — загружаете фото комнаты, сервис
  вытаскивает цветовую палитру и подбирает материалы, чей цвет ближе
  всего к интерьеру (обои, плитка, краска, ламинат).
- **Квартира под ключ** — выбираете шаблон квартиры (студия, однушка,
  двушка), тип ремонта и бюджет — получаете смету по всем комнатам
  с итоговой суммой.

## Как это работает

1. Каталог товаров хранится в SQLite, у каждого товара — цена, упаковка,
   рейтинг и источник.
2. Правила подбора: помещение задаёт требование влагостойкости,
   бюджет — ценовой сегмент, тип работы — способ расчёта упаковок.
3. Подбор по фото: изображение → средние HSV и гистограмма оттенков
   → косинусная близость с цветовым профилем товара → топ-3 совпадений
   с процентом.

## Запуск

    python -m venv .venv
    .venv\Scripts\pip install -r requirements.txt
    .venv\Scripts\python -m uvicorn app.main:app --port 8000

Открыть: http://127.0.0.1:8000 — калькулятор,
http://127.0.0.1:8000/smart.html — умный подбор, фото и квартира под ключ.

## Тесты

    .venv\Scripts\python -m pytest tests -q

67 тестов: расчёты, API, правила подбора, фото-эндпоинты, сценарий
«квартира под ключ».
